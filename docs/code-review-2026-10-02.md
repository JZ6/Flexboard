# Full-repository code review — 2026-10-02

Scope: all 203 tracked files on `dev` at `a45da56` (v2.5.1-dev.10), including
generated files, stubs, resources, documentation, the wrapper jar and the welcome video.
The 36 file-review reports were checked against related callers and, for the most
consequential findings, independently reproduced against the stock dex or with
synthetic inputs. This document is the working ledger for the requested fixes.
File and line numbers refer to `a45da56`; they may shift as fixes are applied.

**Notation:** H = high, M = medium, L = low, N = nit. `V` means independently
reproduced; `R` means reported by the file reviewer and not independently retested.
Findings marked latent require a changed Gboard build or future code shape. Do not
treat an unconfirmed device effect as observed on a device. A passing gate does not
prove device behaviour. Generated `patches-list.json` and the README patch-table
block must only be regenerated by the release pipeline, never hand-edited.
